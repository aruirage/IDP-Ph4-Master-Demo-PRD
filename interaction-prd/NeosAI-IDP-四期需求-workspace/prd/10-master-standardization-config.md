### 6.07 主数据标准化配置端

#### 范围

本期在既有「業務ルール設定」中提供「マスタデータ設定」，用于维护 Zurich 主数据照合组。API 连接、认证和密钥继续在「API設定 → 外部API」维护，本页面不重复配置连接。主数据表、列、提示信息和版本通过 Zurich API 获取，IDP 不维护主数据业务记录。

本模块覆盖配置端闭环。运行时「マスタ照合」节点和 OCR抽出确认的字段级结果应用另行交付。

#### 页面入口

| 项目 | 内容 |
| --- | --- |
| 菜单 | 業務ルール設定 → マスタデータ設定 |
| 路由 | `/v4/standardization` |
| 原主数据维护菜单 | 四期隐藏，源码和路由保留用于回滚 |
| 角色 | 配置管理员 |

#### 页面结构

页面从上到下依次为主数据同步、左侧照合组列表、右侧组配置和底部操作栏。

| 区域 | 内容 |
| --- | --- |
| 主数据同步 | 「マスタデータ同期」、同步图标、同步状态、最终同步时间、「同期」按钮 |
| 照合组列表 | 组名、搜索、追加、组菜单 |
| 组基本信息 | グループ名、適用シーン、主データ |
| 照合字段 | フィールド、マスタ項目、照合方式 |
| 底部操作 | 閉じる、保存 |

组 ID 由系统生成并隐藏，不在配置界面展示。每个组只能配置一种 IDP 字段类型，普通字段、表格字段和案件标准字段不能混配。

#### 主数据同步

1. 页面打开时检查「API設定 → 外部API」中的标准化 API 连接。
2. 连接有效时自动执行主数据同步。
3. 同步调用后端代理，后端调用 `GET /v1/masters`。
4. 根据 `data.masterTables` 更新主数据下拉框。
5. 根据所选主数据的 `columns` 和 `hints` 更新主数据项目下拉框。
6. 不使用 `enabled=false` 或 `deprecated=true` 的数据进行新建配置。
7. 同步成功后显示「マスターデータを最新の状態に更新しました」。
8. 未配置 API 连接时显示空态和「API設定へ」入口。
9. 连接失败时显示连接错误，不允许新建或保存配置。

可见 UI 不展示 `schemaVersion`。版本仍由系统保存，用于判断是否需要刷新 schema。

#### 适用场景

一个照合组可以关联多个业务场景。节点放入业务场景时，根据当前 `sceneId` 自动读取 `sceneIds` 包含当前场景的照合组，不在节点内手动选择组。

保存时校验每个已选场景。组内字段引用的账票必须存在于该场景，字段或表格列也必须存在。场景后续修改导致不兼容时，不自动删除字段，保存时提示错误并阻止保存。

#### 照合字段

| API 字段 | 页面表现 |
| --- | --- |
| `members[].field.documentTypeId` | 帳票タイプ |
| `members[].field.fieldName` | 帳票項目中的普通字段 |
| `members[].field.tableName` | 帳票項目中的テーブル列 |
| `members[].field.columnName` | 帳票項目中的テーブル列 |
| `members[].column` | マスタ項目中的列 |
| `members[].hint` | マスタ項目中的提示信息 |
| `members[].mode` | 照合方式 |

照合方式显示如下。

| API 值 | 日文显示 | 行为 |
| --- | --- | --- |
| `INPUT` | 読み取り（照合に使う） | 参与匹配，不回填 |
| `OUTPUT` | 書き戻し | 不参与匹配，只接收回填 |
| `INPUT_OUTPUT` | 読み取り・書き戻し | 参与匹配并回填 |

新增字段时只展示当前适用场景共同拥有的账票。普通字段和表格列合并展示在一个字段选择器中，用户不配置 API 的 `FIELD`、`TABLE_COLUMN` 类型。

#### 保存与校验

保存按钮执行“校验通过后保存”。校验包括本地业务规则和 `POST /v1/groups/validate`。

| 校验项 | 处理 |
| --- | --- |
| 组名为空 | 阻止保存 |
| 未选择主数据 | 阻止保存 |
| 未选择适用场景 | 阻止保存 |
| 无照合字段 | 阻止保存 |
| 场景中无对应账票 | 阻止保存 |
| 场景中无对应字段或表格列 | 阻止保存 |
| 主数据项目重复 | 阻止保存 |
| 无主要输入 | 阻止保存 |
| 主要输入跨账票或跨表 | 阻止保存 |
| 提示信息用于回填 | 阻止保存 |
| `NONE` 列用于输入 | 阻止保存 |
| 不可写列用于回填 | 阻止保存 |

全部组校验通过后，生成最新 `groupsVersion`，保存组配置和变更履历。任何组校验失败时，不更新版本。

#### 组操作

- 名称変更：输入新名称后更新列表和履历。
- 削除：确认后删除组和关联配置。
- 変更履歴：显示创建者、登记时间，以及每条记录的更新者和更新时间。

#### 版本与持久化

保存成功后生成形如 `2026-11-19-01` 的最新组版本。节点默认使用最近一次保存的版本，不提供手动版本选择。任务启动时冻结实际发送的组和 `groupsVersion`。

正式实现需要持久化以下内容。

- 组配置当前版本。
- 每次保存的完整版本快照。
- 变更履历。
- 节点引用的 `groupsVersion`。
- API 返回的 schema 版本和同步时间。

当前原型使用本地存储验证刷新恢复。生产环境改写为后端持久化。

#### 异常与空态

| 场景 | 表现 |
| --- | --- |
| API 未配置 | 显示「標準化APIが設定されていません」及 API 设置入口 |
| API 连接失败 | 显示「標準化APIに接続できません」 |
| 主数据未同步 | 显示「マスターデータを同期してください」及同步按钮 |
| 保存校验失败 | 保留当前编辑内容，停止保存和版本更新 |
| 适用于场景不兼容 | 保留原配置，提示具体账票或字段错误 |

#### 配置规则

| 项目 | 规则 |
| --- | --- |
| 多场景账票差异 | 只允许添加所有已选场景共同拥有的账票 |
| 场景后续删除字段 | 不自动清理；保存校验发现字段失效时阻止保存并提示修正 |
| 组版本选择 | 默认使用最近保存版本，不允许手工选择 |
| 版本快照保留 | 快照和变更履历保留一年；仍被任务记录引用的快照继续保留至对应任务记录清理 |

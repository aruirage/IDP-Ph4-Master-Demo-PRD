# 主数据照合组配置边界场景

## 功能范围

本文覆盖「组配置」模块的创建、编辑、默认组导入、逐组保存、删除、跨组校验和未保存切换。接口依据为 `主数据API/综合主数据名称标准化API规格书_v1.2_zh-CN.md`，页面规则以 `PRD.zh-CN.md` 第 5.2 节为准。

本期已确认的边界原则：

- 默认组按来源组 ID 与本地组关联，已对应的组原地覆盖，未对应的组追加。
- 首次导入时适用场景和 IDP 字段为空。
- 后续更新保留适用场景，按主数据项目、字段类型和字段名称保留匹配映射。
- 保存和校验以当前组为单位。校验请求包含当前组和其他已保存有效组。
- 已保存组删除后立即更新 `groupsVersion`，删除不记录履历。
- 删除已导入默认组后解除来源映射，下次同步重新追加。
- 所有组名不能重复。
- 同一普通字段、表格列或案件标准字段只能加入一个组。
- 同一组不能混用普通账票字段和表格列。
- 当前组有未保存修改时不能切换、追加或关闭。

本期不处理：

- `deprecated=true` 字段的完整处理，放下一期。
- 多用户并发编辑冲突，放下一期。
- 默认组批量导入后，其他未保存组被关闭而静默丢失。允许用户重新同步。
- 外部账票类型与 IDP 账票类型的自动映射。名称相同但账票类型变化的情况由用户核对。

| 场景 | 预期行为 | 优先级 | 状态 |
| --- | --- | --- | --- |
| 组名为空或只有空格 | 阻止保存当前组，显示日文红色错误 | P1 | 已定义 |
| 组名与其他可见组重名 | 阻止保存当前组，显示「同じグループ名は使用できません」 | P1 | 已定义 |
| 组名包含首尾空格 | 比较重复前去除首尾空格 | P2 | 已实现 |
| 适用场景为空 | 阻止保存，提示设置适用场景 | P1 | 已定义 |
| 同时选择“全シーン”和具体场景 | “全シーン”与具体场景互斥 | P1 | 已定义 |
| 主数据表为空 | 阻止保存，提示选择主数据 | P1 | 已定义 |
| 组内无字段 | 阻止保存，提示设置照合字段 | P1 | 已定义 |
| 某个成员未选择 IDP 字段 | 阻止保存，提示补齐字段 | P1 | 已定义 |
| mode 不在 `allowedModes` 中 | 下拉不可选，保存时再次阻止 | P1 | 已定义 |
| `allowedModes` 为空 | 主数据项目不可选择 | P1 | 已定义 |
| hint 使用非 `INPUT` | 阻止保存 | P1 | 已定义 |
| 同一组重复选择主数据列或 hint | 候选禁用，保存时再次阻止 | P1 | 已定义 |
| 同一组混用普通字段和表格列 | 后续字段选项锁定；保存时阻止 | P1 | IDP 产品限制 |
| 同一普通字段、表格列或标准字段加入多个组 | 阻止当前组保存，并提示所在组 | P1 | IDP 产品限制 |
| 字段不属于所选场景涉及的账票类型 | 阻止保存 | P1 | 已定义 |
| 字段已从账票或数据映射中删除 | 阻止保存，要求重新选择 | P1 | 已定义 |
| 当前场景交集没有可用账票类型 | 字段下拉显示日文空状态，不能添加字段 | P2 | 已定义 |
| 组名超长 | 保存前限制并显示日文错误 | P2 | 待确定长度 |

## 并发与一致性

| 场景 | 预期行为 | 优先级 | 状态 |
| --- | --- | --- | --- |
| 两个管理员同时保存同一组 | 下一期通过版本冲突检测处理 | P1 | 下一期 |
| 页面打开后其他管理员修改了组配置 | 下一期通过版本冲突检测处理 | P1 | 下一期 |
| 默认组预览后客户模板又发生变化 | 应用预览结果，下次同步重新比较 | P2 | 可接受 |
| 主数据 schema 在配置过程中更新 | 下次打开下拉刷新；保存时后端重新校验 | P1 | 后端再校验已定义 |
| 同一按钮被并发点击 | 请求期间禁用 | P1 | 已定义 |

## 集成失败

| 场景 | 预期行为 | 优先级 | 状态 |
| --- | --- | --- | --- |
| `POST /v1/groups/validate` 超时 | 当前组不保存，草稿保留，可以重试 | P1 | 已定义 |
| 客户返回 `FIELD_IN_OTHER_GROUP` | 当前组不保存，提示占用组 | P1 | 已定义 |
| 客户返回未知错误码 | 显示接口返回的日文 `message`，保留草稿 | P2 | 已定义 |
| 目录缺少某个 `memberMode` 显示名 | 使用已有缓存标签；无缓存时显示原始 value | P2 | 已定义 |
| 主数据响应缺少 `configuration` | 本项目不可选择，并提示刷新主数据 | P2 | 需求缺口 |
| 默认组响应包含未知字段类型 | 该项字段映射置空，要求人工确认 | P2 | 需求缺口 |
| 外部 `documentTypeId` 与 IDP 不同 | 不使用外部 ID；按本次已选场景和本地字段名称匹配，变化时由用户核对 | P1 | 已接受 |

## 用户提示

| 错误或状态 | 用户提示 | 后续操作 |
| --- | --- | --- |
| 未保存切换 | 先に現在の変更を保存してください。 | 保存当前组后切换 |
| 组名重复 | 同じグループ名は使用できません | 修改组名 |
| 必填项缺失 | `{缺失字段}を入力してください` | 补齐后重新保存 |
| 默认组更新后有不匹配字段 | 既定グループを更新しました。未設定の照合フィールドを設定して保存してください。 | 设置字段并保存当前组 |
| 默认组新增 | 既定グループを追加しました。適用シーンと照合フィールドを設定して保存してください。 | 选择场景和字段后保存 |

## 恢复路径

### 保存校验失败

用户看到当前组的日文错误。草稿和其他组状态不变。用户修改当前组后可以再次保存，不需要重新加载全部组。

### 主数据或目录获取失败

用户保留已有选择和已缓存显示名。重新展开下拉或点击同步后重试，不能因为刷新失败清空草稿。

### 默认组更新只匹配到部分字段

已匹配字段继续保留。未匹配字段为空，页面显示补全提示。用户补全后只保存当前组，其他组不受影响。

### 删除组失败

删除前先保留当前页面状态。后端删除失败时恢复被删组并显示日文错误，避免页面显示已删除但正式配置未删除。

### 默认组重新出现

已删除的默认组下次同步会重新追加。用户可以再次配置，或以后通过来源映射管理忽略列表，本期不实现忽略名单。

## 测试场景

### 必须测试 P1

- [ ] 空组名、重复组名、空场景、空主数据、空成员和未映射字段均不能保存。
- [ ] 无主输入、主输入全为 `OUTPUT`、主输入账票类型不一致、表格不对齐均不能保存。
- [ ] 普通字段和表格列不能混用；普通字段、表格列和标准字段不能跨组重复。
- [ ] 默认组首次导入后场景和字段为空。
- [ ] 默认组后续更新保留场景，匹配字段保留，不匹配字段清空。
- [ ] 已保存组删除后立即更新版本；删除的默认组下次同步重新追加。
- [ ] 当前组未保存时不能切换、追加或关闭。
- [ ] 保存只更新当前组，校验请求包含当前组和其他已保存有效组。
- [ ] 保存期间重复点击只提交一次，失败后草稿仍保留。

### 应该测试 P2

- [ ] 组名仅首尾空格不同视为重名。
- [ ] “全シーン”和具体场景互斥。
- [ ] 场景交集没有账票类型时，字段下拉不能添加字段。
- [ ] 主数据、目录或默认组请求失败时，已有配置不清空。
- [ ] 删除草稿中的新组不生成版本。
- [ ] 默认组全部字段匹配时不显示补全提示。

### 可以测试 P3

- [ ] 目录缺少显示名时回退到原始 mode value。
- [ ] 默认组响应包含未知字段类型时转人工处理。
- [ ] 连点删除、保存、同步按钮不会产生重复请求。
